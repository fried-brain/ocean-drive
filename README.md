# OCEAN DRIVE — South Beach

A mobile-friendly browser driving-game prototype inspired by Miami Beach's Ocean Drive.

## Play
After GitHub Pages deployment completes, visit:
https://fried-brain.github.io/ocean-drive/

## Controls
- WASD / arrow keys: drive
- Shift: drift
- E: toggle camera view
- R: restart route
- Touch controls are shown on mobile.

## Hosting
GitHub Actions deploys the repository root to GitHub Pages on every push to main.

Three.js is loaded as a classic browser script from jsDelivr. The page includes a visible startup error message if the 3D library cannot load. Use an HTTPS Pages URL rather than opening the downloaded HTML with a content:// URL.
